# @oh-my-pi/rpc-contract

This package holds the generated contract of the omp RPC wire protocol (`omp --mode rpc` / `--mode rpc-ui`). It contains TypeScript types and a JSON Schema for every command, response, and frame. It also carries the contract version that `ready` and `negotiate_protocol` report as `contractVersion`.

The package is private: it is not published to npm. Hosts vendor it from a fork release tag. The package `version` is the RPC contract version.

```ts
import { RPC_CONTRACT_VERSION, RPC_CONTRACT_SCHEMA_HASH, type RpcWireCommands } from "@oh-my-pi/rpc-contract";
import schema from "@oh-my-pi/rpc-contract/rpc-wire.schema.json" with { type: "json" };
```

It also holds the CLI JSON contract: `cli-contract.schema.json`, `cli-contract.json`, and `src/cli.generated.ts` describe the `--json` output of `omp config list|set|reset`, `omp models`, `omp plugin list`, and `omp skill list`, versioned separately as `CLI_CONTRACT_VERSION`.

The source of truth is `packages/coding-agent/src/modes/rpc/wire` for the RPC contract and `packages/coding-agent/src/cli/contract` for the CLI contract. The schema and contract JSON files and `src/*.generated.ts` are generated by `bun run gen:rpc`; do not edit them by hand. See [`docs/rpc-contract.md`](../../docs/rpc-contract.md) for the versioning rules, the bump procedure, and how a host pins the contract.
